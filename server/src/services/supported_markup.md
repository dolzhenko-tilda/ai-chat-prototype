# Поддерживаемая markdown-разметка

Список того, что поддерживается (CommonMark + GFM + распространённые
расширения), с альтернативными синтаксисами и примерами.

---

## 1. Заголовки

**[1]** ATX-заголовки всех шести уровней

```md
# H1
## H2
### H3
#### H4
##### H5
###### H6
```

**[2]** Закрытый ATX

```md
### Заголовок ###
```

**[3]** Setext-заголовки

```md
Заголовок H1
============

Заголовок H2
------------
```

**[4]** Заголовок тегом

```md
<h3>Заголовок</h3>
```

## 2. Абзацы и переносы строк

**[5]** Разделение абзацев пустой строкой

```md
Первый абзац.

Второй абзац.
```

**[6]** Жёсткие переносы: два пробела в конце строки, обратный слэш, `<br>`

```md
Строка с двумя пробелами в конце  
следующая строка

Строка с обратным слэшем\
следующая строка

Строка с тегом<br>следующая строка<br/>и ещё одна
```

**[7]** Неразрывный пробел

```md
Таймаут:&nbsp;30&nbsp;секунд
```

## 3. Выделение текста

**[8]** Курсив

```md
*текст*
_текст_
```

**[9]** Жирный

```md
**текст**
__текст__
```

**[10]** Жирный курсив, в том числе вложенный

```md
***текст***
___текст___
**_текст_**
_**текст**_
*курсив с **жирным** внутри*
```

**[11]** Зачёркнутый

```md
~~текст~~
~текст~
```

**[12]** Подчёркивание

```md
<u>подчёркнутый текст</u>
```

**[13]** Выделение маркером

```md
<mark>выделенный маркером текст</mark>
```

**[14]** Верхний и нижний индексы

```md
12 м<sup>2</sup> и H<sub>2</sub>O
```

**[15]** Клавиши

```md
<kbd>Ctrl</kbd> + <kbd>C</kbd>
```

**[16]** Внутрисловное выделение: со звёздочками срабатывает, с подчёркиваниями — нет

```md
orbita*gateway*v2   выделение срабатывает
snake_case_имя      выделение не срабатывает
```

## 4. Цитаты

**[17]** Простая цитата

```md
> Текст цитаты.
```

**[18]** Вложенные цитаты

```md
> Первый уровень
>> Второй уровень
>>> Третий уровень
```

**[19]** Ленивая цитата: маркер только на первой строке

```md
> Первая строка цитаты
вторая строка без маркера
```

**[20]** Блоки внутри цитаты: заголовок, список, блок кода, таблица

````md
> ## Заголовок
>
> - пункт списка
>
> ```
> код
> ```
>
> | A | B |
> | - | - |
> | 1 | 2 |
````

**[21]** GitHub-алерты

```md
> [!NOTE]
> Заметка.

> [!TIP]
> Совет.

> [!IMPORTANT]
> Важно.

> [!WARNING]
> Предупреждение.

> [!CAUTION]
> Осторожно.
```

## 5. Списки

**[22]** Маркированные списки: `-`, `*`, `+`

```md
- пункт
- пункт

* пункт
* пункт

+ пункт
+ пункт
```

**[23]** Нумерованные списки: `1.` и `1)`

```md
1. первый
2. второй

1) первый
2) второй
```

**[24]** Нумерация с произвольного старта

```md
5. пятый
6. шестой
```

**[25]** Все пункты с номером `1.` — автонумерация

```md
1. первый
1. второй
1. третий
```

**[26]** Вложенные списки, 3+ уровня

```md
- уровень 1
  - уровень 2
    - уровень 3
```

**[27]** Tight и loose списки: плотный без пустых строк, разреженный оборачивает пункты в `<p>`

```md
- плотный
- список

- разреженный

- список
```

**[28]** Смешанная вложенность: нумерованный ↔ маркированный

```md
1. нумерованный
   - маркированный
     1. снова нумерованный
```

**[29]** Чек-листы, в том числе вложенные

```md
- [ ] не отмечен
- [x] отмечен
- [X] отмечен, верхний регистр
- [ ] родитель
  - [x] вложенный
```

## 7. Ссылки

**[34]** Инлайн-ссылка

```md
[текст](https://example.com)
```

**[35]** Заголовок ссылки: двойные кавычки, одинарные, круглые скобки

```md
[текст](https://example.com "заголовок")
[текст](https://example.com 'заголовок')
[текст](https://example.com (заголовок))
```

**[36]** URL в угловых скобках

```md
[текст](<https://example.com/путь с пробелами>)
```

**[37]** Относительные и якорные ссылки

```md
[файл](./docs/file.md)
[уровнем выше](../README.md)
[якорь на странице](#anchor)
[файл с якорем](./file.md#anchor)
```

**[38]** Автоссылки в угловых скобках

```md
<https://example.com>
<http://example.com>
<ftp://example.com>
```

**[39]** Почтовая автоссылка

```md
<mail@example.com>
```

**[40]** Голая ссылка GFM: без разметки и через `www`

```md
https://example.com
www.example.com
```

**[41]** Ссылка-картинка

```md
[![alt](image.png)](https://example.com)
```

**[42]** `mailto:` с темой письма

```md
[написать нам](mailto:mail@example.com?subject=Вопрос%20по%20API)
```

## 9. Таблицы

**[47]** Базовая таблица

```md
| Колонка A | Колонка B |
| --------- | --------- |
| 1         | 2         |
```

**[48]** Выравнивание колонок

```md
| Слева | По центру | Справа | По умолчанию |
| :---- | :-------: | -----: | ------------ |
| a     | b         |      c | d            |
```

**[49]** Без внешних пайпов

```md
Колонка A | Колонка B
--------- | ---------
1         | 2
```

**[50]** Экранированный пайп в ячейке: `\|` и `&#124;`

```md
| Выражение  | Описание |
| ---------- | -------- |
| a \| b     | или      |
| a &#124; b | тоже или |
```

**[51]** Форматирование в ячейках: выделение, инлайн-код, ссылка, картинка, перенос через `<br>`

```md
| Что      | Пример                            |
| -------- | --------------------------------- |
| Текст    | **жирный**, *курсив*, ~~зачёрк~~   |
| Код      | `npm run build`                   |
| Ссылка   | [текст](https://example.com)      |
| Картинка | ![alt](image.png)                 |
| Перенос  | первая строка<br>вторая строка    |
```

**[52]** Неровные таблицы: лишние ячейки отбрасываются, недостающие дополняются пустыми, пустые ячейки внутри строки допустимы

```md
| A | B | C |
| - | - | - |
| 1 | 2 | 3 | 4 |
| 1 |
| 1 |   | 3 |
```

**[53]** HTML-таблица

```md
<table>
  <tr><th>A</th><th>B</th></tr>
  <tr><td>1</td><td>2</td></tr>
</table>
```
