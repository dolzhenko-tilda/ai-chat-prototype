## Абзац

Обычный абзац. Он занимает несколько строк, чтобы были видны межстрочный интервал, длина строки и переносы на границе ширины сообщения. Следом идёт второй абзац — по нему видно вертикальный отступ между абзацами.

Второй абзац, покороче. Здесь заканчивается блок текста и начинается следующий.

## Выделение в тексте

**Жирный текст**, *курсив*, ***жирный курсив***, ~~зачёркнутый~~, <u>подчёркнутый</u>, <mark>выделенный маркером</mark>, `инлайн-код`, верхний индекс м<sup>2</sup>, нижний индекс H<sub>2</sub>O, клавиши <kbd>Ctrl</kbd> + <kbd>C</kbd>, аббревиатура <abbr title="расшифровка аббревиатуры">АББР</abbr>, <small>мелкий текст</small> и <span style="color: #c00">цветной текст</span>.

Типографские символы: &copy; &mdash; &larr; &hellip; и эмодзи 🚀 ✅ ⚠️ ❌.

## Цитата

> Цитата в одну строку.

> Цитата на несколько строк: первая строка цитаты, за ней вторая строка той же цитаты, чтобы были видны отступы и высота блока.
>> Вложенная цитата — второй уровень.

## Выноски

> [!NOTE]
> Выноска «note» — нейтральная заметка в одну строку.

> [!TIP]
> Выноска «tip» — совет. Здесь текст длиннее одной строки, чтобы было видно, как выноска переносит строки и какие у неё внутренние отступы.

> [!IMPORTANT]
> Выноска «important» — важное уточнение.

> [!WARNING]
> Выноска «warning» — предупреждение.

> [!CAUTION]
> Выноска «caution» — необратимое действие.

## Чек-лист

- [x] Отмеченный пункт.
- [ ] Неотмеченный пункт.
- [ ] Пункт с вложенными.
  - [x] Вложенный отмеченный.
  - [ ] Вложенный неотмеченный.

## Код

Инлайн-код внутри строки текста: `npm run build`.

Блок кода с подсветкой языка:

```js
const client = new Client({ url: "https://example.com/api", timeout: 30_000 });
client.on("message", (message) => console.log(message.id, message.state));
```

Блок кода с длинной строкой — должен прокручиваться по горизонтали, а не переноситься:

```bash
command --first-option=value --second-option=value --third-option=value --fourth-option=value --fifth-option=value --output=/var/log/example/output.log
```
